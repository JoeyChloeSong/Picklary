# Picklary v0.7.1 — Korean Editorial Pass

## Goal
Review Korean-facing copy for literal translation, awkward noun-heavy phrasing, inconsistent labels, and English terms that have clearer Korean equivalents.

## Main terminology changes
- 플레이어 → 선수 / 동호인 according to context
- 브래킷 → 대진표
- 포맷 → 경기 방식 / 대회 방식
- 스토리라인 → 선수 이야기 / 관전 흐름
- 뎁스 → 선수층
- 리뷰 신호 → 리뷰 참고 정보
- standings in Korean prose → 순위 / 정규시즌 순위 포인트
- direct second-person 당신 → neutral Korean wording such as 내, 본인, or sentence restructuring

## High-traffic areas reviewed
- Home and master navigation
- DUPR self-check and level pathway
- Paddle Finder, paddle index, and paddle detail labels
- Tour Board, tournament hierarchy, MLP playoff pages, results, and source buttons
- Vision Rating Korean landing page and result explanation
- Play Hub/community matching copy
- Insights / guide titles, summaries, and translated guide body terminology
- Footer, policy, brief, contact, and metadata labels

## Style rule
Keep established pickleball/product terms when they are clearer to Korean players (DUPR, DreamBreaker, dink, reset, Clip Lite, Vision Rating, MLP, PPA), but avoid unnecessary English when natural Korean is clearer.

## Regression safety
- English pages and URLs are unchanged.
- Existing v0.7.0 mobile rules are preserved.
- Existing MLP Dallas playoff data is preserved.
