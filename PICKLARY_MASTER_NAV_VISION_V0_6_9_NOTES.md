# Picklary v0.6.9 — Stable Navigation + Vision Master Design

## Navigation stability
- Desktop masthead uses fixed three-column geometry: brand / eight equal menu slots / language selector.
- Each of the eight primary menu items occupies the same slot on every page.
- Active state no longer changes font weight or underline geometry, preventing horizontal shifts.
- At 1260px and below the site switches to one shared drawer pattern instead of allowing the desktop menu to wrap.
- Mobile uses the same drawer hierarchy in one column; tablet uses two columns.

## Master design
- Vision Rating navy + teal/mint palette is now the global master palette.
- Generic page headers, home hero, Tour Board, tournament group/detail heroes and Clip Lite page header share the same deep navy / teal gradient, grid texture, mint eyebrow, white headings and cool-gray body copy.
- Primary buttons use the Vision mint gradient.
- Visual cards and utility side rail inherit the same glassy navy/teal treatment.
- Tour Board portal cards keep their information hierarchy but no longer use unrelated rainbow gradients.

## Compatibility
- v0.6.8 MLP Dallas results and all existing bilingual content are preserved.
- URLs, canonicals, sitemap rules, Vision Rating language separation, paddles/player graph, and Tour Board event hierarchy are unchanged.
