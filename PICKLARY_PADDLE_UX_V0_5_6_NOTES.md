# Picklary v0.5.6 — Paddle UX upgrade

- Added a compact, all-in-one tier chart before the detailed tier explanations.
- Replaced five horizontal play-profile bars with a six-axis radar chart. The sixth value is the simple average of the five source categories.
- Rebuilt paddle specification tables as stacked mobile rows to prevent right-side clipping.
- Added wrapping protection for long product specifications, notices, and official-source buttons.
- Versioned the main stylesheet to avoid stale Netlify/browser cache collisions.
