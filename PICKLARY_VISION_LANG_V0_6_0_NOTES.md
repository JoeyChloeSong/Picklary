# Picklary Vision Rating language split v0.6.0

- Replaced the shared v0.1.8 package with separate v0.2.3 English and Korean packages.
- `/en/vision-rating/` defaults to the EN package, English quick start, and English sample report.
- `/ko/vision-rating/` defaults to the KO package, Korean quick start, and Korean sample report.
- Both pages include a two-card edition selector so visitors can download either language.
- EN and KO packages use separate local ports and data folders and can coexist on one Windows PC.
- Updated GPU-first / CPU-fallback and local-only processing guidance.
- Added v0.2.3 manual-fallback notes and hexagonal report description.
