# Picklary v0.8.3 update summary

Updated per request:

1. **More paddle imagery**
   - Added additional real-image coverage for several previously missing paddle cards/pages.
   - Improved real-image detection so local product photos also surface correctly.

2. **Expanded Gear Lab selection depth**
   - Added brand-grouped catalogs for **Balls / Shoes / Apparel / Accessories**.
   - Each topic page now shows broader brand coverage and visual product cards.

3. **Tour Board pro player imagery**
   - Replaced the Tour Board pro player menu visuals with real player images for the current featured player set.
   - Player detail pages now also use those real images when available.

4. **Tour Board rankings submenu**
   - Added a new **World Top 10** section under Tour Board.
   - Includes 5 ranking views:
     - Men's Singles
     - Women's Singles
     - Men's Doubles
     - Women's Doubles
     - Mixed Doubles
   - Added an all-in-one overview page plus individual category pages.
