작업일: 2026-10-06  
콘텐츠 기준일: 2026-10-04 (변경 없음)

## 수정 내용

- 홈: 큰 일러스트, 자가진단·편집 주요 카드 2개, 보조 메뉴 카드 4개.
- 모바일: 이미지와 짧은 메뉴명을 중심으로 한 2열 배치. 긴 카드 설명은 상세 페이지로 이동.
- Gear Lab: 패들·공·신발·의류·액세서리의 이미지 카드.
- 투어·학습·도구: 기존 트로피, 선수, 동영상, 패들 그림을 재배치.
- 버튼·메뉴명·링크는 그림 속의 가짜 조작부가 아닌 실제 HTML로 구성.
- 이미지와 설명의 영역을 나누어 겹침 방지.
- 로컬 웹 편집기 다운로드 ZIP에도 새 스타일시트를 포함.

## 이미지 복원 기준

실제 사용한 원본은 제공된 `Picklary_v0.8.4_SOURCE_FINAL.zip`의 메뉴·학습 이미지입니다.
공개 페이지에서 **원본 10개의 이미지 영역 21개**를 활용합니다.
모바일/데스크톱용 480px / 960px WebP와 출처·해시·자르기 좌표를 포함했습니다.

공식 DUPR 인증처럼 보이는 배지, 샘플 점수, 확인되지 않은 실측 주장 영역은 공개 메뉴에 사용하지 않습니다.
메뉴 일러스트와 특정 선수·제품의 실제 사진은 구분했습니다.

## 유지한 기능과 남은 제한

DUPR Self Check의 문항·계산식, Clip Lite의 편집 엔진, 주요 콘텐츠 데이터를 바꾸지 않았습니다.
이번 작업은 디자인 개선이며 경기 결과 업데이트나 새 분석 모델 추가가 아닙니다.

새 메뉴 이미지는 모두 로컬 파일입니다. 기존 선수·제품 사진 31개의 외부 주소와 사용권 확인은 별도입니다.
Windows / Vision Rating 전체 프로그램 ZIP은 여전히 미포함입니다.
실제 브라우저 FFmpeg MP4 출력, 운영 사이트 배포, AdSense 승인을 이 검사로 보장하지 않습니다.

브라우저 검사는 로컬 HTML/CSS/JS와 이미지를 주입하고 외부 요청을 차단한 환경입니다.
저장 기능은 메모리 테스트 대역을 사용합니다. srcset 파일의 존재·해시·크기를 검사했으며, 스크린샷은 큰 이미지 파일로 확인했습니다.
