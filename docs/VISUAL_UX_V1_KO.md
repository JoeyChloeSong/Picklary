# Picklary 비주얼 UX 개편안 v1 — 구현 버전 v1.2.0

## 목적
자가진단·영상 편집·장비·대회·학습 기능이 긴 설명을 읽기 전에도 구분되도록 바꿉니다.
v1.1.0의 핵심 도구를 축소하지 않고, 시각적 진입점과 정보 우선순위를 개선하는 개편입니다.

## 디자인 체계
네이비·딥그린을 주요 배경으로, 민트색을 핵심 동작에 사용합니다.
자가진단은 민트, Vision은 파랑, 영상 편집은 보라, 대회는 금색, 장비는 중립색으로 구분합니다.
색만으로 의미를 전달하지 않고 아이콘과 텍스트를 함께 사용합니다.
제품 카드의 사진과 본문은 정상 문서 흐름의 별도 영역입니다. 대회 배지나 통계가 버튼·본문 위를 덮지 않습니다.
자동 재생 캐러셀이나 강제 팝업은 넣지 않았습니다.

## 이미지와 그림
실제 선수·제품 사진은 기존 media 등록부의 연결을 사용합니다. 다른 선수나 제품 사진을 대신 넣지 않습니다.
새 코트·분석·편집 그림은 SVG 기반 기능 개념도입니다. 분석 결과, 실제 경기 장면 또는 프로그램 화면 캡처라고 표시하지 않습니다.
주요 기능 카드와 제품 사진을 한 덩어리로 합친 새 이미지를 생성하지 않고, 웹 요소로 구성하여 화면 크기에 맞게 바뀌도록 했습니다.
17개 사진은 로컬 자산, 31개는 외부 출처 연결입니다. 이 개편이 새로운 사진 이용권 취득이나 외부 이미지 전체 가용성 검증을 의미하지는 않습니다.

## 유지한 기능
- 기존 코트형 DUPR Self Check의 32개 상황, 적응형 10+10문항, 3D/2D 전환, 해설, 동의 후 기록 저장
- Clip Lite의 원본 로컬 재생, IN/OUT·컷 관리, 출력 설정·취소·오류 처리
- Vision의 로컬 앱 연결 및 별도 프로그램 필요 고지
- 실제 파일·해시·검토 상태에 따른 다운로드 활성화
- 영어·한국어, canonical·hreflang·사이트맵·기존 리디렉트

`V1_1_SOURCE_PRESERVATION.json`은 계산식, 영상 엔진, 문항, 실제 결과 데이터 등 18개 파일의 원본 해시를 기록합니다.
유지 여부는 새 단위 테스트에서 자동으로 비교합니다.
