# Picklary v1.0.0 재설계 감사 결과

**콘텐츠 기준일: 2026-10-04**  
**판정: 소스/정적 빌드 검사 PASS. 운영 배포·이미지 이용권·AdSense 심사는 별도 확인 필요.**

## 결론
v0.8.4는 단순한 이미지 부족이나 CSS 문제만 있었던 것이 아닙니다. 이미지 파일이 존재한다는 검사로는 사진의 대상, 제품 모델, 랭킹 사실관계, 글의 독창적 가치가 보장되지 않았습니다. 따라서 작은 패치 대신 편집 구조와 데이터 관리를 다시 작성했습니다.

실제 Google의 상세 거절 사유는 이번 작업에서 확보되지 않았습니다. 아래 항목은 **소스에서 발견한 문제**이지 Google이 해당 이유로 거절했다고 확인한 내용은 아닙니다.

## 확인한 주요 문제와 처리
| 확인한 문제 | 이번 처리 |
|---|---|
| Jorja Johnson 사진 파일이 Catherine Parenteau 파일과 동일하고, Kate Fahey가 Anna Leigh Waters 사진을 재사용하는 등 다른 인물의 사진 매핑 | 잘못된 복사를 제거하고 선수별 실제 출처와 이름을 다시 연결 |
| Wilson 신발 사진을 다른 브랜드 모델에 사용, 안경 항목에 장갑 등 부정확한 이미지 | 제품을 실제 사진으로 대조할 수 있는 28개 조사 대상 위주로 재구성. 다른 모델 대체 금지 |
| 이전 Top 10의 점수와 순위가 표기한 출처와 맞지 않음 | 이전 수치를 폐기. PPA WPR과 독립 PickleWave Elo를 분리 |
| 수백 페이지에 반복 설명·미검증 비교 점수·외부 링크 중심 정보가 많음 | 9개 주제의 영문·국문 실전 글, 비교 질문, 연습 과제, 노트 도구 중심으로 축소·재작성 |
| 일정 화면의 음수 margin 통계 카드와 절대 위치 배지가 본문을 가림 | 정상 문서 흐름의 그리드로 새 작성; 화면 크기별 겹침 검사 |
| 같은 CSS 파일명에 긴 캐시가 적용되어 수정본이 즉시 반영되지 않을 가능성 | CSS/JS의 내용 해시 파일명 생성 및 HTML 재검증 캐시 |
| 기능/수집 고지와 실제 동작이 엇갈림 | 현재 로컬 도구·이메일·외부 이미지·호스팅 데이터 흐름에 맞춰 고지 재작성 |

기존 파일에서 이름이 다른 사진의 동일 해시도 확인할 수 있었습니다. 이는 새로운 사진 식별을 얼굴 인식으로 수행했다는 뜻이 아니라, 이전의 잘못된 파일 재사용을 발견한 것입니다.

## 새 콘텐츠
- 실전 가이드: **9개 주제 × 2개 언어**
- 제품: **28개**, 패들 10 / 공 4 / 신발 4 / 의류 5 / 액세서리 5
- 선수: **20명**, 프로 19 + 주니어 1 구분
- 이미지 등록부: **48개**, 로컬 17 + 외부 출처 31
- 결과 기록: **4대회**, 확인된 종목/시리즈 행 12개, 미확인 결승 4개
- 렌더링: **76 HTML**, sitemap **66 URL**
- 이전 URL: **110개의 정확한 목적지 연결**. 나머지는 migration 표에서 검토 후 유지/복원 여부 결정

페이지 수 자체를 승인 기준으로 삼은 것이 아닙니다. 미검증·반복 페이지를 재발행하지 않기 위한 선택입니다. `legacy/`에는 원문 자료와 기존 편집기 소스를 보존했습니다.

## AdSense 관련 변경의 의미
Google은 방문자에게 유용한 독창적 콘텐츠, 명확한 탐색과 좋은 사용자 경험을 요구합니다. 외부 자료를 모으거나 조금 바꾸는 것만으로 충분한 가치를 제공한다고 보장되지 않습니다. 이 때문에 글·비교 질문·실습 도구를 중심에 두었습니다.

소유 확인용 메타태그와 `ads.txt`는 유지하되 광고 요청 코드는 넣지 않았습니다. Google은 메타태그/ads.txt 방식의 연결 확인을 안내합니다. 실제 광고 도입 시 필요한 동의/CMP와 위치 검토는 별도입니다.

- Google 사이트 준비: https://support.google.com/adsense/answer/7299563
- Google 복제 콘텐츠 정책: https://support.google.com/publisherpolicies/answer/11190248
- Google 사이트 연결/검토: https://support.google.com/adsense/answer/7584263
- Google CMP 요구사항: https://support.google.com/adsense/answer/13554116

## 배포 전에 꼭 알아둘 기능 변경
기존 Clip Lite의 MP4 출력과 DualCam, AI 점수 기능을 새 사이트가 모두 구현한 것은 아닙니다. 새 공개 도구는 로컬 영상의 분석 노트·타임스탬프·CSV/JSON을 제공합니다. **기존 앱이 반드시 유지되어야 한다면 먼저 기능 유지 계획을 결정하고 Preview에서 확인**하세요. 해당 소스는 `legacy/clip-lite-web/`에 남아 있습니다.
