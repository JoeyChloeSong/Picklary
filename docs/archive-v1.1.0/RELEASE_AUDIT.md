# Picklary v1.1.0 - 기능 복원 검증 보고서

**도구 수정일: 2026-10-06 / 기존 경기 콘텐츠 기준일: 2026-10-04**

## 결론

새 v1.0 디자인에 기존 코트형 자가진단과 브라우저 편집기를 다시 통합했습니다. 단순 설문이나 영상 노트로 대체하지 않았습니다.

**다만 모든 네이티브 프로그램이 복구된 것은 아닙니다.** 이번 첨부파일은 웹사이트 소스이며, Vision Rating 분석 엔진과 Picklary Lite Windows 프로그램 ZIP은 포함되어 있지 않았습니다.

## 복원 범위

| 기능 | 반영 내용 | 남은 확인 |
|---|---|---|
| DUPR Self Check | 32개 상황, 10/20문항, 3D/2D 코트, 샷·강도·타깃·선수 선택, 해설, 저장, JSON | 공식 DUPR 정확도로 검증된 점수는 아님 |
| Clip Lite Web | 로컬 재생, IN/OUT, 컷 추가·삭제·미리보기, MP4/ZIP 추출 연동, 취소·오류 안내 | 실제 브라우저 WASM 추출은 운영 환경에서 최종 검증 필요 |
| Vision Rating | 설치·사용 안내, 실행 중인 로컬 앱 열기, 설명서 배포 | 분석 프로그램 전체 ZIP 필요 |
| Windows 프로그램 공유 | 다운로드 메뉴, 버전·언어·SHA256 관리, 파일 존재 시 버튼 활성화 | 실제 사용 중인 v0.9.8 등 전체 ZIP 필요 |

웹 편집기와 Windows 프로그램은 다릅니다. DualCam, Clip POV, Clip Join, 네이티브 점수판·북마크를 웹에서 새로 구현했다고 표시하지 않았습니다. 기존 PC 설치본을 삭제하거나 덮어쓰지 마세요.

### 검증 방식의 한계

관리형 Chromium의 URL 이동 제한을 변경하지 않고 로컬 HTML/CSS/JS를 주입하여 화면을 검사했습니다. localStorage는 명시적인 메모리 테스트 대역을 사용했습니다. 로컬 H.264/AAC 영상의 Blob 재생는 실제 디코딩으로 확인했습니다.

취소·오류 안내의 엔진 연동 테스트는 대역을 사용했으며, 실제 WASM 인코딩 통과로 간주하지 않습니다. 네이티브 FFmpeg의 1초 컷·2초 합치기 검사도 브라우저 인코더 테스트와는 별개입니다.

실제 WASM 인코더를 검사하는 수동 GitHub Action을 포함했지만 이번 환경에서 실행한 것은 아닙니다.

## GitHub / Netlify 적용

소스 ZIP을 풀고 안의 내용을 저장소 최상위에 올리세요. `.github/`를 포함해야 합니다.

```text
Build command: npm run check
Publish directory: dist
Node version: 22
Base directory: 비워 두기
```

먼저 Preview에서 자가진단, 영상 재생, 짧은 영상 추출을 확인하세요. 최초 추출은 별도 FFmpeg JS/WASM 로드가 필요합니다. 관련 파일은 기본 ZIP에 포함되지 않아 네트워크에서 받거나 `npm run engine:cache`로 먼저 묶어야 합니다.

GitHub Actions의 **Optional real browser export and engine package**를 수동 실행하면 실제 추출 검사와 엔진 포함 배포본 생성을 시도합니다. 성공 여부는 실행 결과로 확인하세요.

## 네이티브 프로그램을 받은 뒤

`releases/`·`data/app-releases.json`·`release:register` 도구로 연결합니다. 실제 파일, 운영자 검토 표시, SHA256이 일치하면 빌드에 포함하고 다운로드 버튼을 활성화합니다. 문서를 설치파일로 연결하지 않습니다. SHA256은 파일 동일성 확인이며 악성코드 검사·정확도 인증은 아닙니다.

이 작업에서 GitHub 업로드, 운영 도메인 배포, Windows 실행, 영상 AI 추론, 이미지 사용권 취득은 실행하지 않았습니다. Google AdSense 승인은 별도 심사이며 보장할 수 없습니다.
