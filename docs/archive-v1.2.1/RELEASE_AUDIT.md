## 기존 기능 보존

32개 상황 데이터, 적응형 10+10문항, 3D/2D 전환, 해설, 동의 후 기록 저장을 포함한 자가진단 코드를 보존했습니다.
Clip Lite의 로컬 재생, 컷 관리, 출력 연동, 취소 및 오류 처리 코드를 보존했습니다.
Vision Rating 로컬 앱 연결 및 파일 검토 후 다운로드 활성화 구조를 유지했습니다.

`V1_1_SOURCE_PRESERVATION.json`에 기록된 **18개 원본 파일의 SHA256**을 테스트에서 비교했습니다.
자가진단 계산·영상 엔진·문항·앱 템플릿·제품·선수·미디어·대회·랭킹 데이터가 포함됩니다.
이 검사와 실제 UI 회귀 검사를 함께 사용했습니다.

## 검증 환경과 한계

브라우저의 탐색 정책을 변경하지 않고 로컬 HTML/CSS/JS를 주입해 화면과 상호작용을 검사했습니다.
외부 네트워크 요청은 차단했고, 저장소 기능의 일부에는 명시적인 메모리 테스트 대역을 사용했습니다.

- **외부 사진:** 48개 등록부 중 로컬 17개, 외부 연결 31개. 외부 31개의 운영 도메인 로딩을 이번 환경에서 검증하지 못했습니다.
- **미리보기 사진:** 제공한 화면 캡처는 외부 이미지 요청을 차단한 테스트 화면입니다. 외부 사진 항목은 일부 '원본 사진 미표시' 안내가 보입니다.
- **사진 권리:** 이번 개편이 사진 이용권 취득을 의미하지 않습니다. 기존 권리 확인표를 유지했습니다.
- **영상:** 실제 로컬 테스트 영상 재생은 확인했습니다. 브라우저 FFmpeg.wasm을 통한 최종 MP4 인코딩은 이번 테스트에서 실행하지 않았습니다.
- **취소/오류:** 테스트용 인코더로 UI 계약을 확인한 것으로 실제 전체 인코딩 완료와 다릅니다.
- **별도 앱:** Vision Rating 전체 설치 ZIP과 Windows v0.9.8 ZIP은 여전히 미포함입니다. 파일 없이 활성 다운로드 버튼을 만들지 않았습니다.
- **운영·광고:** GitHub 저장소 업로드, Netlify 운영 배포, AdSense 신청·승인은 실행하지 않았습니다.

## 배포 파일 검사

GitHub 소스 ZIP을 별도 디렉터리에 다시 압축 해제한 뒤 `npm run check`를 실행해 통과했습니다.
새 빌드도 88 HTML / 78 sitemap URL / 4,272 내부 참조 / 오류 0건이었고, 24개 도구 테스트와 8개 비주얼 테스트가 통과했습니다.
Netlify ZIP 최상위에 `index.html`, `_redirects`, `_headers`, `assets/`, `en/`, `ko/`가 위치합니다.
중첩된 로컬 웹 편집기 ZIP의 CSS/JS 참조 12개와 ZIP 무결성도 확인했습니다.
폰트 파일과 `.env` 등의 비밀 설정 파일은 이번 소스·배포 ZIP에 포함하지 않았습니다.
자세한 기록은 `docs/PACKAGE_VERIFICATION.json`에 있습니다.

## 배포

소스 ZIP을 압축 해제한 **내용을 저장소 루트에** 업로드합니다.
`package.json`, `netlify.toml`, `data/`, `public/`, `scripts/`, `.github/`가 최상위에 있어야 합니다.

```
Node version: 22
Build command: npm run check
Publish directory: dist
Base directory: 비워 두기
```

먼저 Preview에서 실제 사진 로딩과 본인 영상의 짧은 구간 출력을 확인한 뒤 운영판에 반영하세요.
