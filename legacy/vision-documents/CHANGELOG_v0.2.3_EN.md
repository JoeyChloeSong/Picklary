# Picklary Vision Rating Local Web v0.2.3 Changes

## Manual fallback quality

- Low-confidence perspective guesses and court-slot player guesses are no longer displayed.
- Manual fallback starts with empty points and asks the user to mark real locations from the video.
- A high-contrast instruction panel appears directly above the video canvas.
- The next court point or player label is shown live in the instruction panel.
- Assisted mode keeps only actual detections; missing positions are entered manually.
- Verification still completes automatically when all 8 court points and 4 player points are present.
