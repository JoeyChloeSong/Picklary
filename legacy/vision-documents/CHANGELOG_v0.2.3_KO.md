# Picklary Vision Rating Local Web v0.2.3 변경사항

## 수동 전환 품질 개선

- 자동 인식 신뢰도가 낮을 때 표준 원근 기반 코트 추천점과 코트 슬롯 기반 선수 추천점을 더 이상 표시하지 않습니다.
- 수동 전환 시 코트와 선수 위치를 빈 상태로 시작하고 실제 영상에서 직접 지정하도록 안내합니다.
- 영상 캔버스 바로 위에 고대비 안내 패널을 배치했습니다.
- 현재 클릭해야 하는 코트 점 또는 선수 라벨을 안내 패널에 실시간 표시합니다.
- 실제로 감지된 위치가 일부 있는 반자동 모드에서는 감지된 점만 유지하고 누락 위치는 사용자가 직접 지정합니다.
- 8개 코트점과 4개 선수점이 모두 채워지면 기존처럼 자동 Verified 처리됩니다.
